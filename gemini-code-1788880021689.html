Chapter 01

Website Kya Hoti Hai?

Web development ke 3 core building blocks hote hain.

What is it?

Website files ka ek bundle hoti hai jo internet par 24/7 chalne wale computer (Server) par rakhi hoti hain. Jab koi browser me link kholta hai, browser un files ko visually show karta hai.

The Big Three (HTML, CSS, JS)

• HTML (Skeleton / Kankal): Headings, Paragraphs, Images aur Buttons ka structure HTML se banta hai.
• CSS (Skin / Design): Colors, Layout, Dark Mode, Borders aur Animations CSS se aate hain.
• JavaScript (Brain / Dimaag): Button click par menu khulna, pop-up dikhana, data calculate karna JS ka kaam hai.

Static vs Dynamic

• Static Website: Har user ko same content dikhta hai (Jaise Portfolio ya Restaurant Menu). Ye Netlify par 100% free host hoti hai.
• Dynamic Website: Har user ke login aur action ke mutabiq data badalta hai (Jaise Instagram ya YouTube). Iske liye Database aur Backend lagta hai.

Chapter 02

AI Se Clean Code Kaise Lein

AI ko clear instructions dena seekhein taaki bug-free code mile.

AI Prompting Rules

1. Separate Files Mango: AI ko bolo ki index.html, style.css, aur script.js alag-alag file me de.
2. Mobile Responsive: Prompt me hamesha likhein "Fully mobile-responsive using CSS Flexbox/Grid".
3. Complete Code: AI ko bolo "Do not cut or truncate code. Provide 100% working complete code."

Master AI Prompt 
Create a modern, clean, mobile-responsive portfolio website using HTML, CSS, and vanilla JavaScript.
Requirements:
1. Provide code in 3 separate files: index.html, style.css, script.js.
2. Design: Pure black minimalist UI with smooth transitions and rounded cards.
3. Sections: Sticky Navbar, Hero section with Call-to-Action button, Projects grid, and Contact Form.
4. Functionality: Working mobile hamburger menu and client-side form validation.
5. Provide the full code without placeholders.
Agar Error Aaye Toh?

Browser me console error ka text copy karein ya screenshot lekar AI ko dein aur bolein: "This JavaScript error is appearing on line 12. Fix the script.js file."

Chapter 03

Phone Me Acode Setup & Live Test

Apne Android phone ko coding machine banayein.

Step-by-Step Mobile Process

1. Play Store se Acode Editor download karein.
2. Phone ke file manager me ek new folder banayein: my-website.
3. Acode me jakar us folder ko open karein.
4. Teen files banayein: index.html, style.css, script.js.
5. index.html ke <head> me link karein: 

<link rel="stylesheet" href="style.css">
<script src="script.js" defer></script>

6. Upar Play (▶) button dabayein aur turant phone me website chalakar dekhein.

Phone Me Hone Wali 4 Galtiyan

• Capital vs Small letters: Android me Style.css aur style.css alag hote hain. Hamesha small letters use karo.
• Galat Image Path: Phone gallery ka internal folder path na likhein. Image ko hamesha project folder me rakh kar assets/pic.jpg likhein.
• File Extension: File ka naam index.html.txt na ban jaye, verify karein.

Chapter 04

Laptop Par VS Code Workflow

Industry standard developer workflow PC/Mac par.

Setup & Extensions

1. VS Code Install Karein: code.visualstudio.com se.
2. Open Folder: Desktop par folder banakar VS Code me drag & drop karein.
3. Extension: "Live Server" extension install karein.
4. Live Test: index.html par right-click karke "Open with Live Server" chunein. Ab code save karte hi browser automatically reload hoga.
5. Debug: Chrome me F12 dabakar Console tab me red errors check karein.

Chapter 05

Clean Project File Structure

Hamesha standard folder hierarchy follow karein.

Standard Hierarchy 
my-website/
│
├── index.html        # Main Entry Home Page
├── style.css         # Styling & Media Queries
├── script.js         # JavaScript Logic
│
├── assets/           # Media Folder
│   ├── images/       # photos, logos (.png, .webp)
│   └── icons/        # favicons, svg
│
└── README.md         # GitHub Project Details
Path Linking Rule

Agar image assets/images/ me hai, toh HTML me aise link karein:
<img src="assets/images/logo.png" alt="Logo">

Chapter 06

GitHub Par Project Upload Karna

Cloud backup aur hosting ke liye code upload karein.

📱 Phone se Direct Upload (Bina Terminal ke)

1. Mobile Chrome me github.com kholein aur account banayein.
2. New Repository par click karein -> Name dein (e.g. my-site) -> Select Public -> Create.
3. Screen par "uploading an existing file" link par tap karein.
4. Acode folder se index.html, style.css, aur script.js choose karke upload karein.
5. Niche green Commit changes button daba dein. Ho gaya!

💻 Laptop Git Terminal Commands
Terminal 
git init
git add .
git commit -m "Initial website launch"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
Chapter 07

Netlify Par 1 Minute Me Live Deploy

Apni site ko global public link par launch karein.

Phone / PC Deployment Pipeline

1. app.netlify.com par jayein aur "Sign up with GitHub" choose karein.
2. Dashboard par "Add new site" -> "Import an existing project" chunein.
3. GitHub select karein aur permission allow karein.
4. Apni website repository ko select karein.
5. Build command: Khali chhod dein.
6. Publish directory: . ya khali chhod dein.
7. Deploy Site par click karein! 30 seconds me aapko https://something.netlify.app live link mil jayega jise kisi ko bhi share kar sakte ho.

Auto Updates Feature

Aage chalkar jab bhi aap GitHub par file edit ya upload karoge, Netlify bina kuch kiye automatically nayi website live update kar dega!

Chapter 08

Custom Domain (.com / .in) Link Karein

Netlify ke saath apna personal branded domain kaise jodein.

DNS Configuration Fundas

1. Domain provider (Namecheap / Hostinger / GoDaddy) par login karein.
2. Netlify Site Settings -> Domain Management -> Add custom domain par apna domain daalein.
3. DNS Records me add karein:
- A Record: Name @ aur Value 75.2.60.5 (Netlify load balancer IP)
- CNAME Record: Name www aur Value your-site.netlify.app
4. Netlify automatically free SSL Padlock (HTTPS) activate kar deta hai.

Chapter 09

APIs Aur Security Rules

Frontend ko external services se safely connect karna.

⚠️ SECURITY WARNING: Secret API Keys

Kabhi bhi OpenAI key, Payment Secret ya Database passwords script.js me direct mat likho! Koi bhi phone ya PC me "Inspect Element" karke aapki key chura sakta hai.
Secrets ke liye hamesha Serverless backend ya Environment Variables (.env) use karein.

Chapter 10

Firebase Serverless Backend

Bina backend coding ke Login aur Database chalayein.

Main Features

• Auth: Google 1-tap sign-in aur Mobile OTP login bina server likhe ho jata hai.
• Cloud Firestore: NoSQL database jisme app ka real-time data save hota hai.
• Storage: Images aur user files upload karne ki cloud space.

Fix Errors

Mobile Debugging Wizard

Jab website me koi error aaye toh yahan solution dekhein.

❌ Screen par pura White Blank page aa raha hai ▼
Solution: JavaScript me syntax error hai ya HTML file ka naam index.html ke bajaye kuch aur rakh diya hai. Server sabse pehle index.html dhoondhta hai.
❌ CSS Styles apply nahi ho rahe ▼
Solution: 1) File path check karo href="style.css" sahi hai ya nahi. 2) Phone browser purani CSS save kar leta hai (Cache), browser setting me jakar Clear Cache karein.
❌ Netlify par Page Not Found (404) aa raha hai ▼
Solution: Aapne GitHub repository ke andar kisi subfolder me index.html daal di hai. Saari files repository ke main (root) folder me honi chahiye.
